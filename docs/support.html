SAM support

SAM is a private AI assistant. There is no SAM account and no support inbox that reads your chats. Help is public and local.

If something is stuck

  1. On a computer: quit SAM, open it again, and type in chat. Chat is the app.
  2. On iPhone: the App Store app is native 2.0.0. Chat works without a Mac. Pairing is optional.
  3. Newer builds: TestFlight. The older React Native Pocket is TestFlight-only — it is not the store listing.
  4. Still stuck: open an issue at github.com/richhabits/sam/issues. Say what you tapped and what you saw. Do not paste keys, vault files, or pairing codes.

What we will never ask for

API keys, vault folders, .env files, pairing codes, or your Apple password. If a message asks for those, it is not us.

Privacy

The policy is here: privacy. Standalone chat can send a prompt to the AI provider you pick. Files and memory stay on your machine. Offline (Ollama or on-device Apple Intelligence) sends nothing.
